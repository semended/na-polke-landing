# На полке — этап 2: статический лендинг

Каталог и заявки для локального магазина. Покупатель выбирает товары дома, сотрудник получает готовый состав заказа и контакты, подтверждает наличие и договаривается о самовывозе. Оплата — при получении.

Это самостоятельный результат второго этапа учебного проекта. Сайт написан на **HTML, CSS и JavaScript без React, npm и сборки**. Категории, раскрываемые описания и мобильное меню работают; экраны сотрудника показывают будущие возможности. Реальные заказы не принимаются, контактные данные не собираются.

## Запуск

Откройте `index.html` в браузере либо выполните из этой папки:

```sh
python3 -m http.server 4178 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4178. Остановка — `Ctrl+C`.

## Что показать на защите

1. Первый экран: сайт помогает локальному магазину принимать заявки онлайн.
2. «Идея»: покупатель выбирает заранее, сотрудник обновляет товары и получает готовый заказ.
3. Каталог: нажмите «Шоколад», затем «Всё», раскройте описание товара.
4. «Для магазина»: макет недоступного товара и заявка на две упаковки Haribo за 458 ₽.
5. «Как заказать»: выбор, корзина, заявка, подтверждение сотрудником, самовывоз.
6. Мобильное меню и FAQ. Без JavaScript доступны навигация, все товары и раскрываемые описания.

## Границы этапа

Бизнес-логика, авторизация, сохранение заказов, backend и база данных относятся к следующим этапам. Здесь не обещаются доставка, онлайн-оплата, автоматическое резервирование или складской учёт. Цены и характеристики демонстрационные.

Лендинг не импортирует файлы MVP и не использует его `localStorage`. Архив этапа 2 v1 и исходная версия этапа 3 от 28 сентября сохранены отдельно; текущая версия этапа 2 — v2 от 28 октября 2026.

## Файлы

## Публикация и обновление

GitHub Pages публикует корень ветки `main`. Сборка не нужна; `.nojekyll` отключает обработку Jekyll. Обновления делаются коммитом и push. После публикации нужно проверить страницу по её публичному адресу. Откат — revert конкретного изменения и повторная публикация; предыдущие сдаваемые архивы не перезаписываются.
