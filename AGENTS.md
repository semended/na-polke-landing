# На полке: этап 2

Самостоятельный статический HTML/CSS/JS лендинг. React, сборка и зависимости не нужны. Текущий продукт — каталог и заявки для одного локального магазина. Самовывоз и оплата при получении; сотрудник подтверждает наличие. Лицензии на фотографии не выдумывать: происхождение в SOURCES.md.

Сохранять кремовый фон, синий акцент, текущую типографику и адаптивность от 320 px. Реальные заказы, формы сбора контактов, backend и платежи здесь отсутствуют. Не выдавать статические макеты сотрудника за работающие элементы.

Проверять изменённые действия в браузере, desktop/mobile, работу без JavaScript. Предыдущие архивы v1/v2 не перезаписывать. Публикуется корень main через GitHub Pages; факт успешной публикации подтверждать публичной страницей.
