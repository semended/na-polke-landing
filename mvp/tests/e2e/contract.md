# Браузерные сценарии «На полке»

Проверки воспроизводят пример из презентации. Две упаковки Haribo по 229 ₽ дают заявку на 458 ₽. Каждый тест открывает отдельный профиль Chromium с пустой историей.

| Сценарий                    | Что должно быть видно                                                                                                                                                                                                                                                                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Каталог                     | Во время загрузки есть подсказка. Несуществующий поисковый запрос показывает пустой результат, сброс восстанавливает товары. После искусственного сбоя каталог открывается по кнопке повтора.                                                                                                                                           |
| Покупка без регистрации     | Гость находит Haribo, добавляет две упаковки. Корзина и черновик переживают перезагрузку. Пустая форма показывает ошибки имени и телефона. После отправки на экране остаются состав, сумма и введённые контакты. Корзина пуста. Новый профиль покупателя не получает гостевой заказ. Сотрудник открывает ту же заявку из своего списка. |
| Ошибка записи               | При отказе локального хранилища форма остаётся открытой. После перезагрузки покупатель может вернуться к прежней корзине.                                                                                                                                                                                                               |
| Изменение во время отправки | Покупатель меняет количество до завершения оформления. Интерфейс просит проверить корзину, новое количество сохраняется.                                                                                                                                                                                                                |
| Сбой чтения                 | При временной недоступности сохранённых данных приложение предлагает перезагрузку. Когда чтение снова доступно, исходная корзина восстанавливается.                                                                                                                                                                                     |
| Личная история              | Анна открывает свою заявку из истории. В профиле Ивана той же заявки нет, переход по прямой ссылке также закрыт. Сотрудник открывает заявку из списка магазина и видит тот же состав, сумму и контакты.                                                                                                                                 |
| Создание товара             | Отмена сбрасывает незаписанный товар. Сохранённую новую позицию гость находит в каталоге с заданной ценой, фасовкой и описанием.                                                                                                                                                                                                        |
| Обновление ассортимента     | Сотрудник меняет цену и доступность товара. После перезагрузки покупатель видит изменения, недоступный товар нельзя добавить. Сумма ранее оформленного заказа остаётся прежней.                                                                                                                                                         |

## Запуск

Из каталога `mvp` выполните `npm ci` и `npx playwright install chromium`. Откройте два терминала. В первом запустите `npm run dev`, во втором — `npm run test:e2e`. Если Vite выбрал другой адрес, передайте его через `MVP_URL`. Для проверки сборки можно указать локальный адрес из `npm run preview`.

Проверки открывают страницы, вводят вымышленные данные и проверяют результат после действия. Все заказы хранятся в браузерном контексте теста до его закрытия.

### Две вкладки одного браузера

- В открытом оформлении две упаковки стоят 458 ₽. Когда сотрудник в другой вкладке меняет цену с 229 ₽ на 420 ₽, интерфейс показывает 840 ₽ и запрашивает подтверждение. Отправка доступна после согласия.
- В двух редакторах открыт товар за 229 ₽. Первая вкладка сохраняет цену 420 ₽. Вторая пытается сохранить описание из старой версии и видит сообщение о конфликте. Перезагрузка показывает цену 420 ₽ и исходное описание.
